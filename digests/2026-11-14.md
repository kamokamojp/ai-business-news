## 6. OpenAI、エージェントがカード情報を知らずに買い物できる「ChatGPT Wallet」を発表
- 区分：海外 / OpenAI（公式ブログ） / 記事公開日：2026-11-14（JST）
- 要約：OpenAIが、ChatGPTのエージェント「dots」が利用者に代わって買い物を完了できる「ChatGPT Wallet」を発表した。利用者がカードを一度登録すると、購入のたびに商品・合計・カードを確認し、Face IDや指紋などのセキュリティチェックで承認する。決済には実際のカード情報の代わりに使い捨ての支払いトークンが使われ、エージェントや店舗はカード情報を知らない。カードの特典や紛争時の保護は維持されるという。American Express、Mastercard、Visaと共同で開発し、まずは米国のChatGPT Pro加入者（18歳以上、米国発行カード）に限定提供する。事業者向けには「Commerce Partner Playbook」も公開した。
- 実務での見どころ：エージェントによる買い物が「決済」まで到達した転換点で、事業者側はエージェントからの署名付きリクエストをCDNやファイアウォールで誤って遮断しない対応が求められる。まずは米国Pro加入者限定で、利用者による毎回の承認が必須のため、完全な自動購入ではない。将来的には支出上限などの条件付きで事前承認する仕組みも予定されている。
- 一次情報：https://openai.com/index/introducing-chatgpt-wallet/

## 7. SierraとMeta、個人AIエージェントが企業とつながる標準「Personal Agent Protocol（Poppy）1.0」を公開
- 区分：海外 / Sierra（公式ブログ、Metaと共同開発） / 記事公開日：2026-11-14（JST）
- 要約：SierraがMetaと共同開発した、個人AIエージェントが企業とやり取りするための標準「Personal Agent Protocol（Poppy）」のバージョン1.0を公開した。エージェントが自分を名乗り、何ができるかを発見し、企業のエージェントやウェブサイト、APIと連携する手順を定めるもので、OAuth、MCP、OpenAPI、UCPといった既存標準の上に構築されている。Shopifyは全加盟店でPoppyファイルを自動公開し、MetaのAIエージェント「Muse」は訪れるすべてのサイトでPoppyを優先して確認する。Mercury、Synchrony、ターキッシュ エアラインズがデザイン・パートナーとして稼働中で、新たに60社が加わり合計100社超となった。
- 実務での見どころ：ChatGPT Walletと同じ日に出た、エージェント経済のもう半分の標準化だ。Walletが「支払い」を、Poppyが「企業への入り方」を担う。企業側は「/.well-known/poppy.json」を置くだけで対応でき、エージェントごとに個別連携が要らない。ただし仕様はドラフト1.0で今後の変更があり得るとされており、実装はその前提で進める必要がある。
- 一次情報：https://sierra.ai/blog/releasing-poppy
