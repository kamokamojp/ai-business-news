## 1. 2D図面を3Dモデルに　東大発WOGOが「Hacadly AIエージェント」を提供開始
- 区分：日本 / 株式会社WOGO / 記事公開日：2026-11-05（JST）
- 要約：東大発のWOGOは、機械設計における図面・3D CAD作業を自律実行する「Hacadly AIエージェント」の提供を2026年11月5日に開始した。大規模言語モデルと独自の2D図面処理・3D形状処理の技術を組み合わせ、会話による指示で図面やCADデータの読み取りからモデルの生成、照合、修正までを実行する。DXFやPDFの2D図面からSTEP形式の3Dモデルを生成し、履歴のないCADデータのフィーチャー再構築にも対応する。自社ベンチマークでは、2D図面からの3Dモデル生成23件すべてが形状評価を通過し、Claude（ツール連携あり）11件・同（なし）9件に対して約2.1倍・約2.6倍の復元成功率を達成した。フィーチャー再構築は20部品すべてが合格し、編集評価は34件中33件が合格した。ユーザー端末に導入するソフトウェアとして提供し、顧客企業が管理するクラウド内の生成AI環境へ接続する構成も可能で、その場合はデータはWOGOのサーバーを経由しない。料金は個別問い合わせとしている。
- 実務での見どころ：設計現場は人手不足とリードタイム短縮のなか、過去の図面資産を3Dで再活用できるかどうかが実務の分かれ目になる。図面の読み取りから修正までを一気通貫で扱う構成は、設計資産の再利用を進める際の参考になる。ただしベンチマークは自社実施でFreeCAD対象の23件と小規模であり、比較対象はClaude Opus 5.5単体のため、実データでの検証は導入前に確かめる必要がある。設計データを外部サーバー経由にしない構成を選べる点も、機密性の高い図面を扱う企業には押さえておきたい。

## 3. 電話の受付から履歴入力まで一気通貫　DmMiXがコールセンター向けAIエージェント「shiftel」を提供開始
- 区分：日本 / 株式会社ダイレクトマーケティングミックス / 記事公開日：2026-11-05（JST）
- 要約：DmMiXは、コールセンターのインバウンド業務を一気通貫で担うAIエージェント「shiftel（シフテル）」の提供を2026年11月5日に開始した。電話の受付から用件の聞き取りと回答、必要に応じた有人オペレーターへの引き継ぎ、通話後の履歴入力・要約までを一つの流れで対応する。大量の通話データを学習させる「学習型」ではなく、経験豊富なスーパーバイザーが設計したトークスクリプトを「ナレッジ」、話し方や確認手順のルールを「プロンプト」として登録し、AIがその設計どおりに応対する「制御型」を採用し、登録された情報以外を回答しない制御で誤案内のリスクを抑えるとしている。CRMなどの顧客データベースとのAPI連携、24時間365日の稼働、通話データの国内リージョンでの管理に対応する。料金は対応時間・業務範囲に応じた個別見積もり。
- 実務での見どころ：応対品質と正確性が厳しく求められるカスタマーサポート領域では、学習型のハルシネーション懸念が導入の壁になりやすい。人のトーク設計をそのままAIの応対設計に転用する「制御型」は、品質を均一に保ちながら任せる範囲を段階的に広げる考え方として参考になる。5,000席規模の自社運営の知見を生かす設計だが、導入効果の数値は示されていないため、実績の確認は別途必要だ。

## 4. 脆弱性の発見と修正を範囲内で　OpenAIがセキュリティ特化モデル「GPT-6 Cyber」を発表
- 区分：海外 / OpenAI / 記事公開日：2026-11-05（JST）
- 要約：OpenAIは、サイバーセキュリティに特化したモデル「GPT-6 Cyber」を発表した。脆弱性の発見・検証と修正支援を、研究者が定めた範囲内に収めて行うよう訓練したモデルで、ExploitGymでは48.5％を記録し、前身のGPT-5.6 Cyberの32.1％から51％の相対改善となった。範囲外のサービスを誤って攻撃する割合は、展開用の安全プロンプトなしで0.07％（GPT-5.6 Cyberは5.51％）まで下がった。Linuxカーネルの脆弱性1,724件を再現し、948件の権限昇格エクスプロイトを作成、Firefoxの未知の高深刻度脆弱性81件について証拠と再現テストを作成した。APIとCodex経由で、審査を経たDaybreak Redの顧客の一部に先行提供し、順次全Daybreak Red顧客へ拡大する。GPT-5.6 Cyberは全Daybreak Red顧客への提供を開始した。サイバー能力の分類は、OpenAIのPreparedness Frameworkで「Critical」に引き上げられた。
- 実務での見どころ：脆弱性の発見から修正案の作成までをエージェントが回す流れが、実務のセキュリティ運用に入り始めている。ただし利用は審査制のDaybreak Redに限られ、一般提供ではない。48.5％などの数字やLinux・Firefoxの成果はOpenAI自身の評価・発表値で、独立した検証値ではない。守る側の利用拡大と同時に、悪用防止の審査や監視が強まっている点もあわせて読むべきだ。
- 一次情報：https://openai.com/index/introducing-gpt-6-cyber/
